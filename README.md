
## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Crear un archivo llamado config.ts dentro de la carpeta utils, y dentro de él escribir esta próxima linea pero con una de las direcciónes IP en la que esta oyendo el servidor, estas aparecen al correr el backend en una terminal. (Si por alguna razón una direccion no anda puedes probar con otra de la lista):

   ```bash
   export const API_URL = `http://IP:PORT`
   ```

3. Start the app

   ```bash
   npx expo start
   ```
